# როლები, კომუნიკაცია და პასუხისმგებლობები

| როლი | ვინ | პასუხისმგებლობა |
|---|---|---|
| დეველოპერი (Front-end / Full-stack) | სტუდენტი | დაგეგმვა, დიზაინი, კოდი, ტესტირება, გაშვება, დოკუმენტაცია |
| დამკვეთი | Solen | შიგთავსი (ტექსტები, ფასები, ფოტოები), საბოლოო დადასტურება |
| ადმინისტრატორი | Solen-ის თანამშრომელი | ადმინ პანელით ფასების, ფოტოებისა და შეფასებების მართვა |
| შემფასებელი | პროფესიული განათლების მასწავლებელი | პროექტის შეფასება რუბრიკის მიხედვით |

## კომუნიკაცია
- დამკვეთთან: შეხვედრა მოთხოვნებზე, შემდეგ მოკლე ანგარიში ყოველი ეტაპის ბოლოს (ტელეფონი / მესენჯერი).
- ცვლილებების მოთხოვნა ჩაიწერება და სრულდება შემდეგ ეტაპზე.
- პროგრესი აღირიცხება Git ქომითებში და `PROGRESS.md` ფაილში.

## პროფესიული პასუხისმგებლობები
- დამკვეთის მონაცემების დაცვა: პაროლები და გასაღებები არასოდეს ხვდება კოდში ან რეპოზიტორიში.
- ვალიდური, ხელმისაწვდომი (a11y) კოდი: `alt` ტექსტები, `label`-ები ფორმებში, კლავიატურით მართვა.
- ვადების დაცვა და პრობლემების დროული შეტყობინება.
- ლიცენზიების დაცვა: მხოლოდ საკუთარი ან თავისუფალი ლიცენზიის შრიფტები და მასალები.
