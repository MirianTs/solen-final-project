# Solen — საფინალო პროექტის სამუშაო გეგმა

**პროექტი:** Solen-ის ვებსაიტი (solen.ge) — გათბობის, რადიატორებისა და კონდიციონერების სერვისი, თბილისი.
**მიზანი:** ერთგვერდიანი, რესპონსიული საჯარო საიტი სერვისებით, ფასებით, შეფასებებით და კონტაქტით, და
ადმინ პანელი, საიდანაც დამკვეთი კოდის გარეშე ცვლის შიგთავსს.

## 3. რესურსები და მეთოდები

**ტექნოლოგიები:**
- HTML5 (სემანტიკური ტეგები JSX-ით: `header`, `nav`, `main`, `section`, `article`, `footer`, `form`).
- CSS3, Tailwind CSS v4, Flexbox, Grid, CSS ანიმაციები, ღია/მუქი თემა.
- JavaScript/TypeScript, React 19, Next.js 16 (App Router, Server Actions).
- Supabase (Postgres, Auth, Storage), zod ვალიდაცია, Cloudflare Turnstile.

**ინსტრუმენტები:** VS Code, Git/GitHub, GitHub Actions, Vercel, Chrome/Edge DevTools (რესპონსივობის და Lighthouse შემოწმება).

**დიზაინის მასალები:** Solen-ის ლოგო (SVG/PNG, ფერადი და შავ-თეთრი ვარიანტები), ფავიკონები,
სერვისების ფოტოები, Noto Sans Georgian შრიფტი.

**მეთოდი:** იტერაციული განვითარება — ყოველი ეტაპი სრულდება, მოწმდება (typecheck, lint, build) და
ინახება ცალკე, ლოგიკური ქომითით.
