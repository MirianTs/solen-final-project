## გადაჭრილი პრობლემების მაგალითები
- **სპამი შეფასებებში** → Cloudflare Turnstile + ერთი შეფასება მოწყობილობაზე/IP-ზე 30 დღეში + მოდერაცია.
- **ნელი ჩატვირთვა დიდი ფოტოებით** → კომპრესია ბრაუზერში ატვირთვამდე და `next/image`.
- **ღია თემაში ყვითელი ტექსტი არ იკითხებოდა** → ცალკე ფერის ტოკენი `accent-ink` ტექსტისთვის.
- **უფასო ბაზის "დაძინება"** → ყოველდღიური ping ბექაპის ვორკფლოუსთან ერთად.
